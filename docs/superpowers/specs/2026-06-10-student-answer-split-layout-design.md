# Student Answer Split Layout Design

日期：2026-06-10

## 目标

扫码打开的学生答题页在宽屏上改为左右分栏：题目内容在左侧，学生信息、答案填写和提交操作在右侧。窄屏手机继续上下排列，保持可读性和可操作性。

## 范围

- 只调整 `/student/[token]` 学生端页面布局和相关 CSS。
- 不改变题目 API、提交 API、判分逻辑、教师端或二维码生成逻辑。
- 保留现有视觉语言：绿色顶栏、纸色背景、白色内容面板、8px 圆角、现有按钮和输入框样式。

## 布局

宽屏布局：

- 页面顶部保留学生端标题、题号和课堂状态。
- 主内容使用两列网格。
- 左列为题目面板，展示完整题干，支持长题干滚动阅读。
- 右列为答题面板，展示姓名、座号、答案控件、提示/错误/提交成功状态和提交按钮。

窄屏布局：

- 两列网格降为单列。
- 题目面板在上，答题面板在下。
- 表单字段和选项继续使用单列，避免文字拥挤。

## 测试

- 增加学生页布局组件的静态渲染测试，断言题目面板和答题面板分离，且题目面板在答题面板之前。
- 保留现有 `QuestionRenderer` 行为测试。
- 运行 `npm run test`、`npm run lint`、`npm run build`。
