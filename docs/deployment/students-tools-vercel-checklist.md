# Students Tools Vercel Deployment Checklist

日期：2026-06-09

## Production Domain

- Production URL: `https://students.mylifeos457.com`
- Domain owner: Alibaba Cloud account for `mylifeos457.com`
- Vercel project domain: add `students.mylifeos457.com` under Project Settings -> Domains
- Alibaba Cloud DNS record:
  - Type: `CNAME`
  - Host record: `students`
  - Value: use the exact CNAME target shown by Vercel

Do not commit the Vercel-generated CNAME target unless it is already public in Vercel documentation or dashboard screenshots intended for the repository.

## GitHub and Vercel

- GitHub repository must contain the application at the repository root.
- Vercel Production Branch must be `main`.
- Non-`main` branches are Preview deployments.
- Production domain must be assigned only to the Production environment.

## Environment Variables

Set these in Vercel Production:

```text
APP_BASE_URL=https://students.mylifeos457.com
AI_PROVIDER=zhipu
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4
ZHIPU_CHAT_COMPLETIONS_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
ZHIPU_MODEL=GLM-4-Flash-250414
ZHIPU_API_KEY=
DATABASE_URL=
```

Set the real `ZHIPU_API_KEY` and managed persistent database URL only in the Vercel dashboard.

Local development may use:

```text
APP_BASE_URL=http://localhost:3000
DATABASE_PATH=./data/app.db
```

`DATABASE_PATH` is not acceptable for real Vercel Production classroom data.

## Production Data Gate

Before using the deployment for real classroom data:

- `DATABASE_URL` points to managed persistent storage.
- `DATABASE_PATH` is absent in Vercel Production.
- `npm run deploy:check` passes with `VERCEL_ENV=production`.
- QR links generated by the app use `https://students.mylifeos457.com`.
- Zhipu API calls happen only from server code.
- Built assets do not contain the real `ZHIPU_API_KEY`.

## Manual Launch Verification

After deployment:

1. Open `https://students.mylifeos457.com`.
2. Import a non-sensitive test Excel file.
3. Start a test classroom.
4. Open a student QR link from a second browser context.
5. Submit one answer.
6. Confirm the teacher dashboard updates.
7. Generate an AI report with test data.
8. Confirm no real student data appears in Preview deployments.
